# 🤖 AI 量化交易系统 - 系统概览

> 创建日期: 2026-04-15
> 作者: Gavin
> 版本: 1.0.0

## 项目简介

基于 Python + LongPort OpenAPI 的**美股量化交易系统**，集成 WorkBuddy 金融数据能力，支持策略编写、历史回测、模拟交易和实盘交易全流程。

## 系统架构

```
┌─────────────────────────────────────────────────────┐
│                   AI 量化交易系统                      │
├──────────┬──────────┬──────────┬────────────────────┤
│  数据层   │  策略层   │  回测层   │  交易执行层         │
│          │          │          │                    │
│ 长桥API   │ 均线交叉  │ backtrader│ 模拟交易           │
│ WorkBuddy │ RSI反转   │ 绩效分析  │ 实盘交易(LongPort) │
│ SQLite缓存│ 动量策略  │ K线可视化 │ 订单管理           │
├──────────┴──────────┴──────────┴────────────────────┤
│                     风控层                           │
│  仓位控制 | 止损止盈 | 日亏损限额 | 回撤熔断           │
├─────────────────────────────────────────────────────┤
│                     监控层                           │
│  日志系统 | 绩效报告 | 持仓仪表盘                     │
└─────────────────────────────────────────────────────┘
```

## 技术栈

| 组件 | 技术 | 用途 |
|------|------|------|
| 交易通道 | LongPort OpenAPI v4.0.2 | 美股行情 + 交易 |
| 回测框架 | backtrader | 历史数据回测 |
| 数据分析 | pandas + numpy | 数据处理 |
| 技术指标 | pandas-ta | RSI/MA 等指标 |
| 数据存储 | SQLite | 本地行情/交易缓存 |
| 日志 | loguru | 分级日志 |
| 配置 | YAML + pydantic | 参数管理 |
| 可视化 | matplotlib + mplfinance | K线图/资金曲线 |

## 核心设计原则

1. **可插拔策略**: 所有策略继承 `BaseStrategy`，统一 `generate_signal()` 接口
2. **风控独立**: 风控作为交易前的拦截层，不侵入策略逻辑
3. **回测=实盘**: 同一套策略代码，回测和实盘使用完全一致
4. **配置驱动**: 策略参数、风控阈值全部 YAML 配置化
5. **模拟先行**: 先 PaperTrader 验证 → 再小金额实盘
