### 学到的

1. **先查 skill 再写 API 接入**——如果早查 `skills-marketplace` 会节省 1h 试错时间
2. **FMP 免费档有白名单限制**，覆盖率不稳定，不适合做生产依赖
3. **Z-Score + winsorize 对小样本（35 只）真有用**——NVDA ROE 119% 这种异常值不处理会严重扭曲
4. **因子权重调整会显著改变 Top-10**——V0 的价值股（XOM/GS/BAC）在 V1 基本全部掉出
5. **SQLite ALTER ADD COLUMN 幂等方案**：用 try/except 包裹，兼容老 DB
