# Daily 工作复盘

每日一个 markdown 文件，记录当天的工作进度、决策、数据、待办。

## 命名规则

- 格式：`YYYY-MM-DD.md`（ISO 日期格式）
- 例如：`2026-04-23.md`

## 文件结构（见 `TEMPLATE.md`）

1. **今日主线** — 一两段话说明今天的核心
2. **已完成** — 按主题分块列出
3. **今日关键数据** — 账户变化、交易记录、洞察
4. **代码变更清单** — 新增/修改文件 + 数据变更
5. **待办** — 分优先级（明天/本周/下周）
6. **今日反思** — 做得好/可改进/学到的
7. **战果总结** — 量化成绩

## 使用建议

- **每天晚上跑完 daily-scan 后**，花 10-20 分钟填完当天的复盘
- **开始新任务前**，先翻最近 3 天的复盘看有没有未完成的待办
- **周日**做一次周度回顾：翻本周 5 个 daily 文件，提炼到 `docs/obsidian-vault/` 的 dev-XX 文档里

## 快速创建今日文件

```bash
cp daily/TEMPLATE.md daily/$(date +%Y-%m-%d).md
```
